## Objective

On a git push to `App.spec.branch`, bump the App's revision so it rebuilds/redeploys (honoring `spec.autoDeploy`).

## Context

- HMAC-verified webhook receiver (GitHub-style signature). `App.repo/branch/autoDeploy/builder`.

## Files

- `operator/` webhook receiver + revision bump

## Acceptance criteria

- [ ] A signed push to `App.branch` bumps the revision (rejected if the HMAC is invalid); `autoDeploy: false` apps are not bumped.

- The build itself (t001).
